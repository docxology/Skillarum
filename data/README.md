# Skillarum data

Hand-authored inputs and ledgers. Nothing here is generated by a run.

## Contents

| Path | Purpose |
| --- | --- |
| `sources/` | Declarative source profiles (crawl, extraction, generation, targets) |
| `evaluation/` | Live-matrix case plan and human rating files |
| `citations.yaml` | External source records with retrieval dates |
| `claims.yaml` | Manuscript claims with evidence tier and supporting evidence |
| `cover.yaml` | Provenance and accessibility metadata for the manuscript cover |

`data/sources/` contains declarative source profiles. Profiles are inputs, not
runtime crawl state; acquired pages and generated run records belong under
`output/`.

`data/citations.yaml` and `data/claims.yaml` are publication ledgers. Citation
records identify external sources and retrieval dates; claim records identify
the evidence tier and artifact, observation, or citation that supports each
claim. `data/cover.yaml` records the hash, dimensions, caption, alt text, and
limitations of [`../cover/skillarum_cover.png`](../cover/skillarum_cover.png).
`data/evaluation/cases.yaml` defines the live case-study matrix (consumed by
`skillarum evaluate --cases` to attribute observations to declared case ids)
without embedding crawl state or credentials.

## Common commands

From the project root:

```bash
uv run python -m skillarum research validate --json
uv run python -m skillarum research validate --manuscript-dir docs/manuscript --json
uv run python -m skillarum run --profile data/sources/math4wisdom.yaml --backend deterministic
```
