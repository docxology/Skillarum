## 3. Claim rollup

- **Verified in this pass:** demonstrated local contracts listed above, through
  real execution and negative controls; configured source areas and current
  source paths; ordered research input generation.
- **Partially supported:** reproducibility, prompt-injection handling, portable
  packaging, and provenance claims. They hold within the written assumptions;
  they do not establish model obedience, source truth, downstream runtime
  safety, or signer authentication.
- **Unsupported and kept pending:** a causal provider-quality effect or
  independent human-review result. No numbers were manufactured for either.
- **Stale and corrected:** the old repository identity, live-case wording based
  only on profile YAML, historical gate claims, and overbroad formal/security prose.
- **Historical evidence:** undeclared old snapshots remain `unknown` when inspected.
  They were removed from active output before the fresh acquisition. The current
  report contains seven declared-live observations and no fixture or unknown rows.
  Missing telemetry is still unavailable rather than silently zero.
- **Outside the evidence:** population-level web performance, archival
  permanence, full standards compliance, and credentialed provider behavior.

Publisher-deposited DOI records for Clopper–Pearson, Efron, and weighted Cohen
kappa were also checked, and the corresponding definitions and citations were
added alongside the implemented formulas.

The primary-source checks covered [SkillWeaver](https://arxiv.org/abs/2504.07079),
[the Agent Skills specification](https://agentskills.io/specification),
[indirect prompt injection](https://arxiv.org/abs/2302.12173),
[the MCP specification](https://modelcontextprotocol.io/specification/2025-11-25),
and the statistical definitions in [SciPy's exact proportion interval API](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats._result_classes.BinomTestResult.proportion_ci.html)
and [scikit-learn's kappa API](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.cohen_kappa_score.html).
The bibliography is structurally checked as a whole; this is not a claim that
every cited source received a fresh full-text scholarly review.

## 4. Remaining risks

DNS validation is performed before connection but is not IP-pinned across that
boundary. A configured generator command is trusted local code. Redaction covers
recognized patterns, not every possible secret. Filesystem checks have ordinary
concurrent-modification limits; publication uses two atomic renames with a brief
absence window. These limitations are stated in the manuscript and operational docs.

Canonical package directories retain requested human-facing names, whereas the
upstream Agent Skills specification also prescribes slug-matching directory
names. The frontmatter field check is a narrower compatibility claim, not complete
cross-runtime conformance. Report creation timestamps remain operational metadata:
fixed figure bytes do not imply byte-identical evaluation envelopes.

This was an implementation review followed by verification, not an independent
post-build audit. The default suite excludes two opt-in external-provider tests.

The final source suite passed **297 tests**, with two opt-in provider skips and
**90.56% branch-inclusive project coverage**. Ruff checks and formatting passed.
The ordered research build passed all eight steps, including validation of both
raw-response archives. The single test warning is the intentional duplicate ZIP

The fresh selected-bundle acquisition ran on 2026-09-07 PDT (2026-09-08 UTC).
All seven packages are valid and labeled live; five accepted-page records were
truncated to the configured context limit. Neither acquisition nor processing
used an old bundle cache.

The broad Institute sweep retained **899 HTML pages from 899 sitemap URLs**.
Math4Wisdom retained **890 HTML pages from 1,228 discovered URLs**. Its remaining
338 URLs comprise 309 non-HTML responses, 28 size-limit rejections, and one
unavailable video (HTTP 404). There are no unresolved `/wiki/` URLs. This is
complete traversal of the selected HTML discovery graph, with explicit attachment
exclusions; it is not acquisition of every media file or proof of coverage of
unlinked pages. The strict Math4Wisdom archive command consequently returns 1
for incomplete all-URL coverage, and the receipt preserves that result.

Archive hashes, UTC retrieval windows, warning URLs and raw response records
are retained under `output/source_archives/`. The final render, publication and
visual-check results are recorded in `output/reports/review-verification.json`.
That generated receipt describes the final rendered state without making this
implementation pass an independent audit.

Baseline: 255 passed, two opt-in skips; 90.34% coverage. Negative controls
reproduced the report, hydration, PNG hashing, evidence-label, package drift,
repository identity, signature parsing, missingness, and ordinal-bootstrap defects
before their fixes. Early intermediate failures were corrected and are not treated
as successful checks.
